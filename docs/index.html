What Actually Happens

Round Table Workspace creates reviewer candidates for the question, keeps the reviewers that add useful signal, brings them into a round-table debate, and turns the discussion into a decision gate: ship, revise, or reject.

1. Create candidatesStart with possible product, engineering, risk, and user reviewers.
2. Keep signalUse the reviewers that add useful critique instead of filling space.
3. Debate the workMake the panel argue about risks, evidence, and the next action.
4. DecideReturn ship / revise / reject with boundaries you can inspect.

1. AskStart with an idea, change, or launch decision.
2. DiscussUse /room to create a structured exploration trail.
3. DebateUse /debate for product, engineering, risk, and user review.
4. DecideUse ship-check to ship, revise, or reject with boundaries.
