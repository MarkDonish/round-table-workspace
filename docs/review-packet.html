What it is

A local-first round-table review workflow for AI coding agents before trusting generated work.

Who it helps

Developers using Codex, Claude Code, and CLI agents for code, docs, launch copy, or architecture decisions.

What to check

Run the 5-minute local trial and look for a practical ship / revise / reject decision with evidence.

Fresh Clone Trial

No provider key is required for the default demo path.

git clone https://github.com/MarkDonish/round-table-workspace.git
cd round-table-workspace
./rtw demo startup-idea
./rtw ship-check "Should we merge this AI-generated feature?"
./rtw doctor --quick
