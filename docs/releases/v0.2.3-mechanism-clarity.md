# v0.2.3 Mechanism Clarity Release Notes

Release page:
<https://github.com/MarkDonish/round-table-workspace/releases/tag/v0.2.3-mechanism-clarity>

Published: 2026-07-02

## Summary

This release tightens the public evaluation path for Round Table Workspace.
It makes the round-table mechanism easier to understand before a new visitor
decides whether to clone, star, or share the repository.

## What Changed

- README explains the core mechanism in plain English: create reviewer candidates,
  keep the reviewers with useful signal, bring them into a
  round-table debate, then return `ship`, `revise`, or `reject`.
- The public Pages homepage has a `What Actually Happens` section for faster
  first-read understanding.
- A one-page review packet is available for curators, newsletter writers, and
  teams evaluating whether the repo is worth starring or sharing.
- GitHub discovery was improved with the `coding-agents` topic.
- Starter issues are marked `good first issue` and `help wanted` so new
  contributors can find small, claim-safe entry points.
- Pages publishing was adjusted for static docs publishing with `.nojekyll`;
  the live homepage content was updated, although the GitHub Pages API may
  still show an errored build status from the deployment transition.

## Try It

```bash
git clone https://github.com/MarkDonish/round-table-workspace.git
cd round-table-workspace
./rtw demo startup-idea
./rtw ship-check "Should we merge this AI-generated feature?"
./rtw doctor --quick
```
